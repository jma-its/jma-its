Slide 2

Why this lecture matters

Study the original slide first. Then read the web explanation.

Students often say: “The computer is slow.” But this is only a symptom. A slow computer may have a CPU problem, RAM problem, storage problem, network problem, server problem, printer queue, or overheating. Good support does not guess randomly. Good support checks the chain, finds the slow part, and fixes the correct problem. Key idea: Slow is a symptom, not a cause.

Think and answer

Is “the computer is slow” a cause?

Show answer

No. It is a symptom.

Slide 7

Bottleneck = narrow point

Study the original slide first. Then read the web explanation.

Imagine water moving through pipes. One narrow pipe limits the whole flow. In a computer, data also moves through parts: CPU, RAM, disk, network, server, and output devices. If one part is too slow, other parts wait. The user only sees the result: “It is slow.” Key idea: A bottleneck is the part that limits the whole system.

Think and answer

What is a bottleneck?

Show answer

The part that limits the whole system.

Slide 50

Practice setup

Study the original slide first. Then read the web explanation.

Student task Read each problem card. Underline the symptom. Choose: CPU, RAM, disk, network, server, printer, heat, or app problem. Write the first thing to check. Teacher flow Let students answer first. Ask: “What evidence do you see?” Show the likely answer. Repeat with a similar case. Do not reward random guessing. Reward evidence and clear reasoning.

Lesson summary
