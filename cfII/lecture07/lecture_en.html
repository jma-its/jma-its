Slide 4

The Support Workflow

Study the original slide first. Then read the web explanation.

Use the same order every time. 1. Check Is the workplace ready? 2. Find What is the cause? 3. Report Explain clearly. 4. Fix Solve or ask expert. 5. Test Did it work? Do not skip steps. A skipped step often creates a wrong answer. Support workflow = repeatable method.

Think and answer

Why should the same order be used every time?

Show answer

A repeatable order reduces mistakes and missed checks.

Stay calm, ask questions, check simple things, change one thing at a time, and record actions.

Slide 7

What is a maintenance checklist?

Study the original slide first. Then read the web explanation.

Maintenance means preventing problems before they become serious. Check the computer before work starts. Check power, cables, input devices, output devices, and network. Write down small problems early. A small loose cable can become a big classroom or hospital problem. Maintenance is troubleshooting before the emergency.

Think and answer

What does maintenance do before an emergency?

Show answer

It finds and records small problems early.
