How to Make Your Web Page

Software I · Step by Step

What will you make?

You will make one web page.

Your page may be published on the college website as your student achievement.

You can write about yourself, your hometown, your village, your country, your hobby, or your future plan.

Write only information that you agree to publish.

Before you start

  1. Use a computer, not only a phone.
  2. Connect a mouse to the USB port if you have one.
  3. Use the mouse. It is easier than the touchpad.
  4. Check that you can open Microsoft Edge.
  5. Check that you can find the keyboard keys: Ctrl, S, F5, Enter.

Mouse words

Part 1: Open the template page

  1. Open Microsoft Edge.
  2. Click the address bar at the top of Edge.
  3. Type this address:
jma-its.github.io/jma-its/mypage.html
  1. Press Enter.
  2. You should see the web page template.

Lifehack: you do not need to type https:// at the beginning.

Part 2: Save the page to Downloads

Now you need your own copy of the page.

  1. On the page, press Ctrl + S.
  2. A save window will open.
  3. Choose Downloads / ダウンロード.
  4. File name: write your student file name if teacher gives it. For practice, use:
mypage.html
  1. If you can choose file type, choose Webpage, HTML only.
  2. Click Save / 保存.

Now the file is on your computer.

If Edge makes an extra folder

Sometimes Edge saves like this:

mypage.html mypage_files

This is not dangerous, but it can confuse you.

For this lesson, the important file is:

mypage.html

Part 3: Open Downloads folder

  1. Open File Explorer / エクスプローラー.
  2. On the left side, click Downloads / ダウンロード.
  3. Find your file:
mypage.html
  1. If you cannot find it, look at the top of the file list.
  2. If you still cannot find it, ask teacher before editing the wrong file.

Part 4: Open the same file in two ways

Open in Edge

Double click mypage.html.

This shows the web page.

Open in Notepad

Right click mypage.html.

Choose Open with → Notepad.

This edits the code.

Same file. Two different uses.

Part 5: Open with Notepad

  1. In Downloads, find mypage.html.
  2. Right click the file.
  3. Choose Open with / プログラムから開く.
  4. Choose Notepad / メモ帳.
  5. If you cannot see Notepad, choose Choose another app.
  6. If needed, click More apps.
  7. Choose Notepad.

Do not open with Word. Use Notepad.

What you see in Notepad

In Notepad, you see the code.

Do not be afraid. You do not need to understand everything.

You only need to find the edit areas.

STUDENT EDIT AREA 1 CHANGE COLORS AND BACKGROUND HERE STUDENT EDIT AREA 2 CHANGE TEXT HERE

Page has two big parts

1. Settings and style

This is near the top.

It changes colors, fonts, background, size.

<style> CSS design is here </style>

2. Visible page

This is lower in the file.

It has the text and photo.

<body> Your text is here </body>

Very important: do not delete code symbols

HTML and CSS need special symbols.

If you delete them, the page can break.

Do not delete Why?
< and > Start and end of an HTML tag
/ End tag, for example </p>
" Text around file names, for example "photo.jpg"
: and ; CSS needs them
{ and } Start and end of CSS block

Part 6: Change text safely

Change only the words between the start tag and end tag.

Before

<h1>My Web Page</h1> <p>WRITE YOUR NAME OR NICKNAME HERE.</p>

After

<h1>My Personal Page</h1> <p>My name is Ram.</p>

Do not delete <h1>, </h1>, <p>, or </p>.

Part 7: Change colors safely

In CSS, change only color words first.

Before

background-color: lightblue; color: darkblue;

After

background-color: pink; color: black;

Do not delete : or ;.

Easy color words: white, black, pink, yellow, lightgreen, purple.

Part 8: Add your photo

For the easiest way, rename your photo to:

photo.jpg
  1. Put your photo in the same Downloads folder.
  2. Make sure the photo file name is exactly photo.jpg.
  3. In the HTML file, keep this line:
<img src="photo.jpg" alt="My photo">

If the photo name is different, the photo will not show.

If teacher gives you a student number

Teacher may ask you to name your files like this:

26hi001.html 26hi001.jpg

Then your image code must use the same photo name:

<img src="26hi001.jpg" alt="My photo">

File name in code = real photo file name.

Part 9: Save in Notepad

  1. After editing, click inside Notepad.
  2. Press Ctrl + S.
  3. This saves the file.
  4. Do not close Notepad yet.

If you do not save, your web page will not change.

Part 10: Open your saved file in Edge

  1. Go back to Downloads folder.
  2. Find your saved HTML file.
  3. Double click the HTML file.
  4. It should open in Edge.
  5. If Edge is already open, press F5 to refresh.

Remember: Edit → Save → Refresh.

Common mistakes

Problem Check this
Text did not change Did you press Ctrl + S in Notepad?
Browser shows old page Did you press F5 in Edge?
Photo does not show Is photo file name exactly the same as in src=""?
Page looks broken Did you delete <, >, ", ;, or { }?
You edited, but wrong file opens Maybe you edited one file and opened another file. Check Downloads.

Final check before sending

  • My page opens in Edge.
  • My text is changed.
  • My photo is visible.
  • My colors are changed.
  • I saved the file.
  • I refreshed the browser.
  • I did not write private information.

What to send to teacher

Send the real files. Do not send only a screenshot.

your_page.html your_photo.jpg

If teacher gives special file names, use teacher's file names.
