Part 1 — Switches, 0 and 1, and binary numbers

Slide 5

Part 1 — The switch

Read the picture first. Then read the explanation below.

The first important idea is the switch.

A switch is simple.
When the switch is OFF, the circuit is open.
Current cannot flow.
We can call this state 0.

When the switch is ON, the circuit is closed.
Current can flow.
We can call this state 1.

This looks very simple.
But simple is good for machines.
A machine can check OFF or ON very clearly.

This is the beginning of digital computers.
Zero and one are not only math symbols.
They can be real physical states in a circuit.

Think and answer

What are the two states of a switch?

Show answer

OFF and ON. We can call OFF = 0 and ON = 1.

Why computers use two states

Read the picture first. Then read the explanation below.

Computers use two states because machines need clear differences.

Human language is rich, but it can be unclear.
Electrical circuits need something more exact.

A low voltage can mean 0.
A high voltage can mean 1.
The exact voltage can be different in different devices.
But the idea is the same:
one range means 0,
and another range means 1.

This makes the computer more reliable.
The signal does not need to be perfect.
It only needs to be clearly low or clearly high.

That is why two states are so useful.

If a computer is made from switches, then it is natural for the computer to write numbers using 0 and 1.

Slide 9

Binary Place Values: 1, 2, 4, 8

Read the picture first. Then read the explanation below.

Now we must understand place values.

In decimal, places are 1, 10, 100, and so on.
But in binary, places are 1, 2, 4, 8, and so on.

Please look at the top of the slide.
The places are 8, 4, 2, and 1.
Each place can be 0 or 1.

If the place is 0, we do not add that value.
If the place is 1, we add that value.

For example, 0011 means:
0 times 8,
0 times 4,
1 times 2,
1 times 1.
So 0011 equals 3.

This is the key rule.
Binary places grow by powers of two.

Binary Numbers with Switches

Read the picture first. Then read the explanation below.

Now the binary number becomes physical.

Here we have four switches.
The switches have values: 8, 4, 2, and 1.

If a switch is OFF, it is 0.
It adds nothing.
If a switch is ON, it is 1.
It adds its value.

Look at the examples.
0001 means only the 1 switch is ON.
So the value is 1.

0010 means only the 2 switch is ON.
So the value is 2.

0011 means the 2 switch and the 1 switch are ON.
2 plus 1 equals 3.

This is very important:
computer numbers can be shown by many ON/OFF switches.

Slide 11

Simple Binary Addition with Switches

Read the picture first. Then read the explanation below.

Now we look at very simple binary addition.

Example 1 is 1 plus 1.
In binary, 1 is written as 01.
So we add 01 plus 01.

In the 1s place, one plus one makes two.
But one binary place can only show 0 or 1.
So two does not fit in the 1s place.
We write 0 in the 1s place and carry 1 to the 2s place.
The result is 10.
Binary 10 means decimal 2.

Example 2 is 2 plus 2.
In binary, 2 is written as 010.
010 plus 010 gives 100.
Binary 100 means decimal 4.

Computers add using 0 and 1.

1 + 1 = 10 in binary. We carry to the next place.

Part 2 — Logic from switches

Slide 13

From one switch to a rule

Read the picture first. Then read the explanation below.

One switch gives one bit.
One bit can be 0 or 1.

But if we use two switches, we can make a rule.

For example, a lamp turns ON only when switch A is ON and switch B is ON.
If only one switch is ON, the lamp is still OFF.
If both switches are ON, the lamp turns ON.

This is already computer logic.
The computer follows a rule exactly.

This idea is very important for software too.
Software also uses exact rules:
if this happens, then do that.

Think and answer

What can two switches make?

Show answer

Two switches can make a rule, for example AND logic.

Slide 14

AND logic

Read the picture first. Then read the explanation below.

Now we study the first logic rule: AND.

AND is a strict rule.
A and B must both be 1.

0 AND 0 equals 0.
0 AND 1 equals 0.
1 AND 0 equals 0.
1 AND 1 equals 1.

Only the last case gives 1.
Both inputs must be true.

A human example:
the door opens only if the card is valid AND the door is not locked.
If one condition is missing, the door does not open.

This is the beginning of computer logic.

Think and answer

When is AND equal to 1?

Show answer

AND is 1 only when both inputs are 1.

Back to lesson map ↑
Slide 15

OR logic

Read the picture first. Then read the explanation below.

The second logic rule is OR.

OR is more flexible.
One true input is enough.

0 OR 0 equals 0.
0 OR 1 equals 1.
1 OR 0 equals 1.
1 OR 1 equals 1.

So OR means:
if A is 1 or B is 1, the output is 1.

A hospital example:
if the patient has strong pain OR high fever, staff must check the patient.
One warning sign is enough.

OR is not only math.
It is a rule for action.

Think and answer

When is OR equal to 1?

Show answer

OR is 1 when at least one input is 1.

Slide 16

NOT logic

Read the picture first. Then read the explanation below.

The third logic rule is NOT.

NOT reverses the signal.
NOT 0 becomes 1.
NOT 1 becomes 0.

This is useful when we need the opposite condition.

A human example:
if the test is NOT complete, do not archive the file.

Computer systems use NOT all the time.
Not ready.
Not connected.
Not allowed.
Not found.

Later, in software, you will see the same idea:
if not connected,
if not paid,
if not found.

So NOT is a simple but very useful rule.

Think and answer

What does NOT do?

Show answer

NOT reverses the signal: NOT 0 = 1, NOT 1 = 0.

Part 3 — Relay: electricity controls electricity

Slide 18

Part 2 — Relay

Read the picture first. Then read the explanation below.

Now we move to the relay.

A human can press a switch with a finger.
But can electricity press a switch?
Yes.
A relay does this.

A relay uses electromagnetism.
A small current in one circuit creates a magnetic field.
The magnetic field moves a metal part.
The moving metal part opens or closes another circuit.

So electricity controls electricity.
This is a very important bridge from physics to computer logic.

Think and answer

What is the relay idea?

Show answer

A small electrical current uses electromagnetism to control another circuit.

Slide 19

Relay physics

Read the picture first. Then read the explanation below.

Let us follow the relay step by step.

A relay has a coil of wire.
When current flows in the coil, the coil becomes an electromagnet.
The electromagnet pulls a metal armature.
The armature moves a contact.
The contact opens or closes another circuit.

The chain is:
current,
magnetic field,
force,
moving contact,
output current.

This is a perfect example of physics becoming technology.
A physical effect becomes a useful device.

Think and answer

What physical chain happens inside a relay?

Show answer

current → magnetic field → force → moving contact → output current.

Slide 28

Relay vs Vacuum Tube vs Transistor

Read the picture first. Then read the explanation below.

This large comparison slide is very important.

Look from left to right.
The relay is an electromechanical switch.
It uses magnetism to move metal contacts.
It is useful, but slow and mechanical.

The vacuum tube is an electronic switch.

It is faster because it does not move a metal contact.
