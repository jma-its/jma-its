JHTS 1.6 · LEVEL 0 STUDENT GUIDE

JHTS 1.6 — Your First Training

Level 0 · System Basics

Start with the basics. Follow the instruction on the screen, one task at a time.

  1. Open the websiteOpen the link given by your teacher in Chrome or Edge. Choose Training Academy in the left menu. Do not download the website.
  2. Start Level 0Find Level 0 — Start here: System Basics. Click Start level.
  3. Read the first two messagesRead each short message. Click I understand — continue after each one.
  4. Follow the guided stepsOpen Patients. Switch the language to Japanese, then back to English. In the Patients Search box, type P-10001.
  5. Visit three more pagesFollow the next instructions: open Appointments, then Insurance, then Save & Reports. The task changes automatically when you open the correct page.
  6. Complete the final patient checkReturn to Patients. Read the Patient ticket shown on screen. Search for that patient, click View details, and compare the Patient ID and date of birth. Click Confirm this patient only when they match.
  7. Check your resultReturn to Training Academy. To unlock Level 1, you need at least 80% and zero critical patient-confirmation errors. You can try Level 0 again.
  8. Save your work laterProgress stays in this browser. When your teacher asks you to submit, open Save & Reports, enter your name and student ID together in the Student name field, and download BOTH the JSON database and TXT report.

IMPORTANT · Use fictional data only. Do not click Reset Data. The website interface supports English and Japanese; this guide is also available in Nepali.

JHTS 1.6 — はじめての操作ガイド

Level 0 · システムの基本

最初は基本操作から始めましょう。画面に表示される指示を、順番に一つずつ実行してください。

  1. サイトを開く先生から案内されたリンクを Chrome または Edge で開きます。左側のメニューから「Training Academy」を選びます。ウェブサイトのダウンロードは不要です。
  2. Level 0 を開始する「Level 0 — Start here: System Basics」を見つけ、「レベルを開始」を押します。
  3. 最初の説明を読む最初の２つの説明を読み、その都度「理解しました — 続ける」を押します。
  4. ガイド付きの操作「Patients」を開き、表示言語を「日本語」に切り替え、次に「English」に戻します。「Patients」の検索欄に P-10001 を入力します。
  5. ３つのページを開く次の指示に従い「Appointments」→「Insurance」→「Save & Reports」の順に開きます。正しいページに移動すると課題が自動的に進みます。
  6. 最後の患者確認「Patients」に戻り、画面の「Patient ticket」を読みます。該当する患者を検索し、「詳細表示」を開きます。患者IDと生年月日が一致することを確認してから「この患者を確認」を押します。
  7. 結果を確認する「Training Academy」に戻って結果を確認します。Level 1 に進むには通常80%以上の得点と、重大な本人確認ミスが０件であることが必要です。再挑戦できます。
  8. 提出するときの保存方法学習状況はこのブラウザーに保存されます。先生から提出の指示が出たら「Save & Reports」の氏名入力欄に氏名と学籍番号を一緒に入力し、JSON と TXT の両方をダウンロードしてください。

重要：実在の患者情報を入力しないでください。「Reset Data」を押さないでください。画面の表示言語は英語と日本語です。

JHTS 1.6 — सुरु गर्ने छोटो मार्गदर्शिका

Level 0 · प्रणालीका आधारभूत कुराहरू

पहिले आधारभूत काम सिक्नुहोस्। स्क्रिनमा आएको निर्देशन एक–एक गरी पूरा गर्नुहोस्।

  1. वेबसाइट खोल्नुहोस्शिक्षकले दिएको लिङ्क Chrome वा Edge मा खोल्नुहोस्। बायाँपट्टिको मेनुबाट Training Academy छान्नुहोस्। वेबसाइट डाउनलोड गर्नुपर्दैन।
  2. Level 0 सुरु गर्नुहोस्Level 0 — Start here: System Basics खोजेर Start level थिच्नुहोस्।
  3. पहिला दुई सन्देश पढ्नुहोस्सुरुका दुई छोटा सन्देश पढ्नुहोस्। प्रत्येक सन्देशपछि I understand — continue थिच्नुहोस्।
  4. निर्देशनअनुसार अभ्यास गर्नुहोस्Patients खोल्नुहोस्। भाषा Japanese मा बदल्नुहोस् र फेरि English मा फर्कनुहोस्। Patients को Search बाकसमा P-10001 लेख्नुहोस्।
  5. थप तीन पृष्ठ खोल्नुहोस्त्यसपछि निर्देशनअनुसार Appointments → Insurance → Save & Reports खोल्नुहोस्। सही पृष्ठ खोल्दा कार्य आफैँ अर्को चरणमा जान्छ।
  6. अन्तिम बिरामी पहिचान जाँच गर्नुहोस्फेरि Patients मा जानुहोस्। स्क्रिनमा देखिएको Patient ticket पढ्नुहोस्। बिरामी खोज्नुहोस्, View details खोल्नुहोस् र Patient ID तथा जन्ममिति मिलाउनुहोस्। सबै विवरण मिलेपछि मात्र Confirm this patient थिच्नुहोस्।
  7. नतिजा जाँच्नुहोस्Training Academy मा फर्केर नतिजा हेर्नुहोस्। Level 1 खोल्न कम्तीमा 80% अंक र बिरामीको पहिचान पुष्टि गर्दा कुनै गम्भीर गल्ती नभएको हुनुपर्छ। Level 0 फेरि गर्न सकिन्छ।
  8. पछि काम सुरक्षित गरेर बुझाउनुहोस्तपाईंको प्रगति यही ब्राउजरमा सुरक्षित हुन्छ। शिक्षकले बुझाउन भनेपछि Save & Reports को Student name बाकसमा आफ्नो नाम र विद्यार्थी नम्बर सँगै लेख्नुहोस्। JSON र TXT दुवै फाइल डाउनलोड गर्नुहोस्।

ध्यान दिनुहोस्: वास्तविक बिरामीको जानकारी प्रयोग नगर्नुहोस्। Reset Data नथिच्नुहोस्। प्रणालीमा English र Japanese भाषा छन्; यो निर्देशन नेपालीमा पनि उपलब्ध छ।
