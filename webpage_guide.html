How to Make Your Web Page

Software I · Final Web Page Project

Goal

Make one beautiful web page.

Your page may be published on the college website as student achievement.

Write only information that you agree to publish.

You do not need one big topic

You can write a little about many things.

Small simple sentences are OK.

More text = better score.

Choose some ideas from this menu.

Easy page structure

You can use this order:

1. Title 2. Photo 3. About me 4. My hometown or country 5. My hobbies and likes 6. Why I study here 7. My future plan

Public page rule

This page can be public.

Do not write private information.

  • No home address.
  • No phone number.
  • No passport or visa information.
  • No private family problems.
  • No photo of another person without permission.

Files for your project

For the easiest project, use these two files:

mypage.html photo.jpg

Put them in the same folder.

One photo is enough.

Very important: file names

Computer needs exact names.

Good

mypage.html photo.jpg 26hi001.html 26hi001.jpg

Bad

my photo.jpg My Page Final (1).html 私の写真.jpg photo new!!.jpg

Rule: no spaces, no Japanese, no symbols.

Open the file in two ways

Browser

Double click HTML file.

Use browser to see the page.

Notepad

Right click → Open with → Notepad.

Use Notepad to edit code.

How to edit

  1. Open mypage.html with Notepad.
  2. Find: CHANGE HERE.
  3. Write your text under the instruction.
  4. Change colors if you want.
  5. Press Ctrl + S to save.
  6. Go to browser.
  7. Press F5 to refresh.

Photo rule

If your code says:

<img src="photo.jpg">

Then your photo file name must be exactly:

photo.jpg

If the name is different, the photo will not show.

Change text

Find this area in the code:

<!-- CHANGE TEXT HERE --> <h1>My Web Page</h1> <p>WRITE ABOUT YOURSELF HERE.</p> <p>WRITE ABOUT YOUR HOMETOWN HERE.</p> <p>WRITE ABOUT YOUR FUTURE HERE.</p>

Write your own sentences.

Change colors

Find this area in the code:

/* CHANGE COLORS HERE */ background-color: lightblue; color: darkblue;

Change only color words.

Try: pink, yellow, lightgreen, black, white, purple, blue.

For higher score

  • Write more English sentences.
  • Add more sections.
  • Use beautiful colors.
  • Use different fonts.
  • Use one good photo.
  • Make the page easy to read.
  • Write about your future plan.
  • Write why you came to Japan or chose this school.

Send to teacher

Send your HTML file and your photo file.

mypage.html photo.jpg

Do not send only a screenshot.

Teacher needs your real HTML file.

Remember

Edit → Save → Refresh

If you do not save, nothing changes.

If you do not refresh, you cannot see the new page.
