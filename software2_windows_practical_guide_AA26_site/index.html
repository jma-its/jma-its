1. Start clean in aa26

What to do

  1. Open Documents → aa26.
  2. Delete old files you do not need, or make one new folder named CARD_TEST_yourname.
  3. Work only inside your new task folder.

Explanation

This step makes your work easier to check. A clean folder helps you avoid mistakes.

Example: CARD_TEST_Alex
Be careful: Do not delete files that your teacher told you to keep.

2. Open your folder

What to do

  1. Find your task folder in aa26.
  2. Double-click the folder to open it.

Explanation

Double-click means two quick left-clicks. You must open the correct folder before you start creating files.

3. Create a new folder

What to do

  1. Right-click empty space.
  2. Click New.
  3. Click Folder.
  4. Type the folder name.
  5. Press Enter.

Explanation

You will use folders to organize your files. The folder name must match the name on your task card.

Example: original, copies, moved, found_file
Be careful: Check capital letters, small letters, spaces, and underscores carefully.

4. Create all subfolders from your card

What to do

  1. Read the card carefully.
  2. Create every folder that the card asks for.
  3. Check all names again.

Explanation

Many students lose points because they forget one folder or write the wrong name. Make all folders first.

5. Create a text file

What to do

  1. Right-click empty space.
  2. Click New → Text Document.
  3. Type the file name and press Enter.
  4. Open the file and write a short sentence.
  5. Save the file.

Explanation

A text file is a simple file for notes. In your practical card, you may need to make several text files.

Example: patient_note.txt
Be careful: Do not leave the file empty if the card asks you to write inside it.

6. Rename a file in Windows 11

What to do

  1. Right-click the file.
  2. Click Rename.
  3. Type the new name.
  4. Press Enter.
  5. Fast method: select the file and press F2.

Explanation

Rename changes the file name. In Windows 11, the Rename button is in the right-click menu. This is an important Windows 11 skill.

Example: note1.txt → patient_note.txt
Be careful: If Windows shows .txt, do not delete it unless your teacher told you to.

7. Copy and move

What to do

  1. Copy keeps the original and makes a new file.
  2. Move changes the place of the file.
  3. To be sure while dragging: hold Ctrl to COPY.
  4. To be sure while dragging: hold Shift to MOVE.

Explanation

This is the most important trick for weak students. Ctrl + drag is safer for copy. Shift + drag is safer for move.

Be careful: If you move a file by mistake, it disappears from the old folder.

8. Search for a file

What to do

  1. Click the Search box in File Explorer.
  2. Type the file name you need.
  3. Wait for the result.
  4. Open or copy the file after you find it.

Explanation

Search helps you find a file when you do not remember its exact location.

Example: hospital_sample.txt

9. Copy a file from aa26_source

What to do

  1. Open aa26_source.
  2. Find the correct file.
  3. Copy it.
  4. Open your found_file folder.
  5. Paste it there.

Explanation

Your card may ask you to find one common file and put it in your own folder. This shows that you can find, copy, and paste.

Example: Copy hospital_sample.txt to found_file

10. Create a picture in Paint

What to do

  1. Open Paint.
  2. Draw something simple.
  3. Click Save As.
  4. Choose PNG.
  5. Type the file name and save it.

Explanation

Paint is an easy way to create one picture file. Your task card may ask you to save a simple image in PNG format.

Example: simple_picture.png
Be careful: Save the picture in the correct folder.

11. Open with

What to do

  1. Right-click the file.
  2. Click Open with.
  3. Choose the correct app.
  4. For a text file, choose Notepad.
  5. For a picture, choose Paint or Photos.

Explanation

Use Open with when Windows opens a file with the wrong app, or when you want a different app.

Example: .txt → Notepad, .png → Paint

12. Check file properties

What to do

  1. Right-click the file.
  2. Click Properties.
  3. Read the type, location, size, and date modified.

Explanation

Properties help you check whether the file is correct and whether it is saved in the right folder.

Example: Type: Text Document (.txt)

13. Make a ZIP file

What to do

  1. Right-click the folder you need to pack.
  2. Click Compress to ZIP file.
  3. Wait for Windows to create the ZIP file.

Explanation

A ZIP file is a packed folder. ZIP is useful for sending files by e-mail or messenger, and for downloading from websites.

Be careful: The ZIP file is not the same as the extracted folder. Both may be needed in your final result.

14. Extract the ZIP file

What to do

  1. Right-click the ZIP file.
  2. Click Extract All...
  3. Choose the place if needed.
  4. Open the extracted folder and check the files.

Explanation

To use the files inside a ZIP, you usually need to extract it first.

Be careful: After extracting, check that the files inside are really there.

15. Create a shortcut (optional)

What to do

  1. Right-click the EXE file.
  2. Click Show more options.
  3. Click Send to.
  4. Click Desktop (create shortcut).

Explanation

A shortcut is a quick link. It is useful for programs or games. Stronger students can do this optional step.

Be careful: A shortcut is not the original EXE file.

16. Final check before you call the teacher

What to do

  1. Open your main task folder.
  2. Show all required subfolders.
  3. Show your text files and other files.
  4. Show the ZIP file.
  5. Show the extracted folder.
  6. Show the special file from the card.

Explanation

Before you call the teacher, check everything yourself. Clean, organized work is easier to grade.

Be careful: Do not call the teacher too early. First check names, locations, and ZIP/extracted folders.
